HomeCare 기술 명세서v0.2 · 개발팀용

퇴원 환자가 홈펌프(특수항암기계)로 항암제를 44시간 자가 투여하는 동안, 하루 3번 점검 알람 + 3가지 체크 + 이상 상황 대처 + 의료진 공유용 기록을 제공하는 모바일 웹앱입니다.

설계 원칙 서버 의존성 없이 환자 단말에서 완결되도록 설계합니다. 어드민/관리자 콘솔은 v1 범위에서 제외하며, 의료진은 외래 방문 시 환자가 보여주는 PDF로만 기록을 확인합니다.

한 페이지 흐름 요약

  1. 의료진 입력 — 수동 입력 → 잠금
  2. 환자 인수 — 단말 전달, 짧은 온보딩
  3. 대시보드 — 진행률, 다음 알람 카운트다운
  4. 점검 플로우 — 눈금 / 잠금장치 / 온도센서
  5. 이상 상황 — 5가지 시나리오 + 직통 전화
  6. 기록 — 타임라인 + 눈금 추이 차트
  7. PDF — 외래 진료용 리포트
  8. 완료 — 눈금 0 → 병원 복귀 안내

저장 · 동기화 전략

QR 기반 데이터 전달

Safari의 로컬 저장소 제한(7일 자동 삭제, 크로스 도메인 차단)을 우회하기 위해 QR코드 기반 데이터 전달 방식을 채택합니다.

  • 의료진 단말에서 환자 정보를 입력하고 QR 코드 생성
  • 환자 단말에서 QR 스캔 → URL 열기 → 앱에 데이터 자동 로드
  • 서버 저장소 불필요, 개인정보 처리 동의 부담 최소화

QR 데이터 인코딩

// state/AppContext.tsx
const generateQRData = (): string => {
  const data: QRData = {
    patient,
    startAt: startAt.toISOString(),
    alarmTimes,
  };
  // JSON → URI 인코딩 → Base64
  return btoa(encodeURIComponent(JSON.stringify(data)));
};

// QR URL 형식: https://homecare.app?d={encoded_data}

QR 데이터 로딩

// URL 파싱하여 상태 로드
useEffect(() => {
  const params = new URLSearchParams(window.location.search);
  const encoded = params.get("d");
  if (encoded) {
    const json = decodeURIComponent(atob(encoded));
    const data = JSON.parse(json) as QRData;
    setPatient(data.patient);
    setStartAt(new Date(data.startAt));
    setAlarmTimes(data.alarmTimes);
    setMode("patient");
    goTo("intro");
    // URL에서 쿼리스트링 제거
    window.history.replaceState({}, "", window.location.pathname);
  }
}, []);
Safari 호환성 QR 방식은 Safari의 ITP(Intelligent Tracking Prevention) 제한을 완전히 우회합니다. 데이터가 URL을 통해 전달되므로 쿠키/localStorage 제한에 영향받지 않습니다.

export function useTick(intervalMs = 60_000) {
  const [, set] = useState(0);
  useEffect(() => {
    const id = setInterval(() => set((n) => n + 1), intervalMs);
    return () => clearInterval(id);
  }, [intervalMs]);
}

const handleDownloadPDF = async (): Promise<void> => {
  if (!reportRef.current) return;
  setIsGenerating(true);

  // HTML → Canvas
  const canvas = await html2canvas(reportRef.current, {
    scale: 2,
    useCORS: true,
    backgroundColor: "#ffffff",
  });

  // Canvas → PDF (A4)
  const imgData = canvas.toDataURL("image/png");
  const pdf = new jsPDF({
    orientation: "portrait",
    unit: "mm",
    format: "a4",
  });

  // 비율 유지하며 페이지에 맞춤
  const pageWidth = pdf.internal.pageSize.getWidth();
  const ratio = pageWidth / canvas.width;
  pdf.addImage(imgData, "PNG", 0, 0, pageWidth, canvas.height * ratio);

  // 다운로드: HomeCare_홍길동_12345678_20260526.pdf
  const fileName = `HomeCare_${patient.name}_${patient.mrn}_${dateStr}.pdf`;
  pdf.save(fileName);

알람 · 푸시

요구사항

  • 하루 3번, 의료진이 설정한 시각에 알림 (아침/점심/저녁)

구현 — useAlarmScheduler 훅

// hooks/useAlarmScheduler.ts
export const useAlarmScheduler = ({
  alarmTimes, enabled, onAlarm
}: UseAlarmSchedulerOptions): void => {
  const lastFiredSlot = useRef<string | null>(null);

  useEffect(() => {
    if (!enabled) return;

    const checkAlarm = (): void => {
      const now = new Date();
      const currentTime = formatHHMM(now);
      const todayKey = formatDate(now);

      // 각 알람 시간과 비교
      for (const [slot, time] of Object.entries(alarmTimes)) {
        if (currentTime === time) {
          const key = `${todayKey}-${slot}`;
          if (lastFiredSlot.current !== key) {
            lastFiredSlot.current = key;
            onAlarm(slot as AlarmSlot);
          }
        }
      }
    };

    const id = setInterval(checkAlarm, 60000);
    return () => clearInterval(id);
  }, [alarmTimes, enabled, onAlarm]);
};

다음 알람 계산

// state/AppContext.tsx
const getNextAlarmSlot = (
  now: Date,
  alarms: AlarmTimes
): AlarmSlot | null => {
  const nowMins = now.getHours() * 60 + now.getMinutes();
  const slots = [
    { slot: "morning", mins: toMinutes(alarms.morning) },
    { slot: "noon",    mins: toMinutes(alarms.noon) },
    { slot: "evening", mins: toMinutes(alarms.evening) },
  ];
  // 현재 시간 이후의 가장 가까운 슬롯 반환
  for (const { slot, mins } of slots) {
    if (mins > nowMins) return slot;
  }
  return "morning"; // 내일 아침
};

  • 모든 데이터가 IndexedDB에 있으므로 동기화 충돌 우려 없음
  • 웹 매니페스트로 홈 화면 설치 지원: display: 'standalone', orientation: 'portrait'

  1. resolveSlot() — 현재 시각으로부터 morning/noon/evening 매핑

  3. feedbackForChecks() — 안심 메시지 분기
